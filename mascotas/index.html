Identificación digital y relevamiento responsable de perros.

El aviso se prepara para enviar por el canal oficial que habilite el municipio. No se publica automáticamente.

Registro municipal

El registro de perros y la emisión de medallas requieren acceso autorizado del municipio. Esta es la primera interfaz pública del módulo.

Cada medalla deberá apuntar a una URL permanente como qrcrea.com.ar/mascotas/?id=IDENTIFICADOR. Las fichas se cargarán desde una base de datos con permisos de acceso.
